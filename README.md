# StudPlan v5

Учебное приложение для упрощения планирования учебы.

## 📱 Основные возможности
* **Задачи и дедлайны:** Запись различных задач и контроль сроков выполнения.
* **Расписание:** Добавление расписания вручную или автоматически *(автоматическое добавление доступно только для группы 4.301-1)*.
* **Прогресс:** Отслеживание прогресса выполнения своих задач.
* **Уведомления:** Гибкие настройки уведомлений, чтобы ничего не забыть.
